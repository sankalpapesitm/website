Project Overview: FraudShield UPI

FraudShield UPI is a next-generation, AI-powered secure payment assistant app designed to protect users from UPI-based payment fraud, phishing, and scanner-based scams.

It combines a premium React Native mobile frontend for smooth, native user experiences with a robust Python/Flask machine learning backend running real-time risk classification.

Real-Time Threat Analysis

When you scan a UPI QR code or transfer money, the app runs predictive AI checks in the background (using Random Forest and XGBoost machine learning models) to assess transaction risk.

Risk Categorization

Instant safety ratings (SAFE, RISKY, or DANGEROUS) are displayed before you authorize any transfer, warning you of known fraudulent UPI IDs, malicious links, or anomalous location profiles.

Biometric & Device Security

Includes multi-factor authentication, biometric logins (fingerprint/PIN), and local GPS location monitoring to prevent unauthorized access and detect location anomalies.

Personalized QR & Profiles

Enables secure money receipts via custom QR code generation, along with wallet balance monitoring and user trust score auditing to maintain standard payment safety metrics.

Community Fraud Reporting

Users can directly file reports against fraudulent UPI addresses, instantly feeding threat data back into the machine learning models to protect the entire ecosystem dynamically.
